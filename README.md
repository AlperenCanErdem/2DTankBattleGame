# 🛡️ Tank 2025 - 2D Arcade Battle Game

A 2D retro-style tank battle game developed using **Java** and **JavaFX**. The game features dynamic enemy AI, collision detection, and smooth animations entirely built with object-oriented programming principles.

## 🎮 Game Features
Based on the project requirements and implementation:

* **Smooth Animations:** Realistic tank tread animations during movement for both player and enemies.
* **Player Control:**
    * Movement in 4 cardinal directions using Arrow Keys.
    * Shooting mechanism with cooldowns using the 'X' key.
    * 
* **Enemy AI:**
    * Enemies spawn randomly at the top of the map.
    * Semi-random movement patterns and automatic shooting behavior.
* **Physics & Collision:**
    * **Indestructible Walls:** Blocks movement and bullets.
    * **Explosion Effects:** Visual effects trigger when bullets hit walls or tanks.
    * **Respawn System:** Player and enemies respawn with a delay after being destroyed.
* **UI & Game States:**
    * Real-time **Scoreboard** and **Lives** counter.
    * **Pause Menu** (Continue, Restart, Exit).
    * **Game Over Screen** with restart options.

## 🛠️ Technologies Used
* **Language:** Java 8+
* **GUI Framework:** JavaFX (No SceneBuilder, pure code)
* **IDE:** IntelliJ IDEA / Eclipse

## 🚀 How to Run
